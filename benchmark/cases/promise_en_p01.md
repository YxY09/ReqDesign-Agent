# PROMISE NFR (English) — Project 1

## Functional Requirements

### F001: The system shall have a MDI form that allows for the viewing of the graph and the data table.

### F002: The system shall display Events in a vertical table by time.

### F003: The system shall display the Events in a graph by time.

### F004: The system shall display Events or Activities.

### F005: The display shall have two regions:  left 2/3 of the display is graphical  right 1/3 of the display is a data table

### F006: The data displayed in both the nodes within the graph and the rows in the table are MSEL Summary data

### F007: The table side of the display shall be split into 2 regions: sequential and temporal.

### F008: The top 1/4 of the table will hold events that are to occur sequentially.

### F009: The bottom 3/4 of the table will hold events that occur according to its relevance to current time.

### F010: The system shall color code events according to their variance from current time.

### F011: The system shall display data from the Sync Matrix 1.0 and Exercise Management Tool 1.0 applications

### F012: The system shall link Events back to either the Sync Matrix 1.0 or the Exercise Managment Tool 1.0 applications for modifications.

### F013: The system shall allow modification of the display.

### F014: The system shall offer a display of all the Events in the exercise.

### F015: The system shall filter data by: Venues and Key Events.

### F016: The system shall allow a user to define the time segments

### F017: The system shall display the local and exercise time in separate clocks

### F018: The system shall offer the ability to pause and resume the refresh of data.

### F019: The system shall provide charts for the Activity or Event actual versus assumed time.

### F020: The system shall provide a history report of changes made to the Activity or Event data

## Non-Functional Requirements

### N001 [Performance]: The system shall refresh the display every 60 seconds.

### N002 [Look & Feel]: The application shall match the color of the schema set forth by Department of Homeland Security

### N003 [Usability]: If projected  the data must be readable.  On a 10x10 projection screen  90% of viewers must be able to read Event / Activity data from a viewing distance of 30

### N004 [Availability]: The product shall be available during normal business hours. As long as the user has access to the client PC  the system will be available 99% of the time during the first six months of operation.

### N005 [Usability]: If projected  the data must be understandable. On a 10x10 projection screen  90% of viewers must be able to determine that Events or Activities are occuring in current time from a viewing distance of 100

### N006 [Security]: The product shall ensure that it can only be accessed by authorized users.  The product will be able to distinguish between authorized and unauthorized users in all access attempts

### N007 [Usability]: The product shall be intuitive and self-explanatory.  :  90% of new users shall be able to start the display of Events or Activities within 90 minutes of using the product.

### N008 [Performance]: The product shall respond fast to keep up-to-date data in the display.
