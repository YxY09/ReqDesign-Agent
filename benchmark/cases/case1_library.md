# 图书管理系统需求

## 项目背景
某高校图书馆需要一套图书管理系统，方便学生和管理员进行图书借阅和管理。

## 用户角色
- 学生：可以注册账号、登录系统、搜索图书、借阅图书、归还图书、查看借阅记录
- 管理员：可以登录系统、添加图书、删除图书、修改图书信息、查看所有借阅记录

## 功能需求
1. 用户注册与登录：学生可以通过学号和密码注册和登录系统
2. 图书搜索：学生可以按书名、作者、ISBN搜索图书
3. 图书借阅：学生可以借阅状态为"可借"的图书，每人最多同时借阅5本
4. 图书归还：学生可以归还已借阅的图书
5. 借阅记录：学生可以查看自己的借阅历史
6. 图书管理：管理员可以添加、删除、修改图书信息
7. 借阅管理：管理员可以查看所有用户的借阅记录

## 业务约束
- 同一时间一本图书只能被一个用户借阅
- 每个学生最多同时借阅5本图书
- 借阅期限为30天，超期需要缴纳罚款
- 管理员不能借阅图书

## 异常流程
- 用户尝试借阅已被借出的图书时，系统提示"该图书已被借出"
- 用户借阅数量达到上限时，系统提示"借阅数量已达上限"
- 用户逾期未还时，系统标记逾期状态并提示用户

## 非功能需求
- 系统响应时间不超过3秒
- 支持至少100个并发用户
- 数据定期备份
