# PROMISE NFR — Project 2

## 功能需求 (Functional Requirements)

### F001: El sistema permitirá a un agente inmobiliario consultar información MLS

### F002: El usuario podrá obtener indicaciones para llegar a una propiedad seleccionada

### F003: El usuario podrá descargar citas e información de contacto de los clientes

### F004: El sistema debe mostrar imágenes de propiedad claras en los resultados de la búsqueda

### F005: El sistema actualizará o creará nuevos listados de propiedades en el MLS

### F006: El agente inmobiliario podrá generar un informe CMA basado en criterios de propiedad

### F007: El sistema podrá llamar al vendedor o al comprador para programar una cita

### F008: El agente inmobiliario será notificado de las citas de nuevos clientes después de la sincronización automática con el sistema de oficina

### F009: El agente inmobiliario podrá recuperar un mapa que muestre la ubicación de las propiedades para un área específica

### F010: El sistema notificará al agente inmobiliario cuando un vendedor o comprador responda a una solicitud de cita

### F011: El producto permitirá al usuario guardar los resultados de la búsqueda de propiedades

## 非功能需求 (Non-Functional Requirements)

### N001 [Look & Feel]: La apariencia del sistema se ajustará a los estándares de interfaz de usuario del dispositivo inteligente

### N002 [Look & Feel]: La interfaz de usuario debe tener botones de menú estándar para la navegación

### N003 [Look & Feel]: El sistema deberá tener una apariencia profesional

### N004 [Look & Feel]: El producto deberá tener una combinación de colores y fuentes uniformes

### N005 [Usability]: El sistema debe ser utilizado por agentes inmobiliarios sin formación

### N006 [Usability]: El sistema será intuitivo y autoexplicativo

### N007 [Usability]: El producto debe ser fácil de aprender para un agente inmobiliario

### N008 [Usability]: El producto utilizará símbolos y palabras que sean naturalmente comprensibles para la comunidad de agentes inmobiliarios

### N009 [Performance]: El producto producirá resultados de búsqueda en un tiempo aceptable

### N010 [Performance]: Los resultados de la búsqueda se devolverán a más tardar 30 segundos después de que el usuario haya introducido los criterios de búsqueda

### N011 [Performance]: El producto deberá generar un informe CMA en un tiempo aceptable.

### N012 [Performance]: El informe CMA se devolverá a más tardar 60 segundos después de que el usuario haya introducido los criterios del informe CMA

### N013 [Performance]: El producto sincronizará contactos y citas en un tiempo aceptable

### N014 [Performance]: El producto se sincronizará con el sistema de oficina cada hora

### N015 [Availability]: El producto estará disponible para su uso las 24 horas del día los 365 días del año

### N016 [Availability]: De 1000 accesos al sistema, el sistema está disponible 999 veces

### N017 [Fault Tolerance]: El producto funcionará en modo fuera de línea siempre que la conexión a Internet no esté disponible

### N018 [Fault Tolerance]: El producto permitirá al usuario ver los resultados de búsqueda descargados previamente, informes y citas CMA

### N019 [Fault Tolerance]: El producto conservará las preferencias del usuario en caso de avería

### N020 [Fault Tolerance]: El 100% de las preferencias de usuario guardadas se restaurarán cuando el sistema vuelva a estar en línea

### N021 [Scalability]: El producto debe ser compatible con varios usuarios remotos

### N022 [Scalability]: El producto debe admitir 1000 usuarios simultáneos

### N023 [Scalability]: El producto deberá ser capaz de manejar los 1000 usuarios existentes. Se espera que este número crezca 5 veces durante el próximo año.

### N024 [Usability]: El producto debe ser instalado por un agente inmobiliario no capacitado sin recurrir a instrucciones impresas por separado

### N025 [Usability]: El 90% de los agentes inmobiliarios no capacitados podrán instalar el producto en su dispositivo sin instrucciones impresas

### N026 [Portability]: Se espera que el producto se ejecute en los sistemas operativos Windows CE y Palm.

### N027 [Security]: Solo los agentes inmobiliarios registrados podrán acceder al sistema.

### N028 [Security]: Todo usuario del sistema deberá estar autenticado y autorizado

### N029 [Security]: El producto evitará que se introduzcan datos incorrectos en sus datos
