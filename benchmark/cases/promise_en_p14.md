## Non-Functional Requirements

### N001 [Security]: Each team owner will need to use a username and password in order to be authenticated to reach the team owners page

### N002 [Security]: The Commissioner will be the only authorized user per league to adjust league settings.

### N003 [Look & Feel]: Each page shall contain a navigation menu which shows the index into which the current page is contained.

### N004 [Look & Feel]: Each page shall contain a similar format with action items in one location and navigation buttons in a different location.

### N005 [Look & Feel]: The message board shall contain the 5 most recently posted messages on the league page. The messages will contain up to the first 150 characters of the message.

### N006 [Usability]: A new user shall be able to navigate through the league and team pages within 30 seconds of reaching the start-up page.

### N007 [Usability]: Users shall be able to reach the add  drop  and trade player pages with one click from the team owners page.

### N008 [Usability]: Users shall be able to view at least 25 NFL player statistics and points on each page.

### N009 [Usability]: The application shall ask the user to confirm dropping a player or trading a player before performing the action.

### N010 [Performance]: The application shall be able to complete every user transaction within one fourth of a second of receiving the request over the network.

### N011 [Availability]: The application shall have a downtime of at most 10 minutes per year.

### N012 [Operational]: The application shall run on a web application server.

### N013 [Operational]: A primary database will be used to store cached data for active users.

### N014 [Operational]: A secondary database will be used to store historical statistics and data.

### N015 [Maintainability]: Application updates shall occur between 3AM and 6 AM CST on Wednesday morning during the middle of the NFL season.

### N016 [Maintainability]: New System version releases shall be released at the beginning of each NFL season.
