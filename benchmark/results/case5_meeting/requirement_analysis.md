# 需求分析说明

## 项目名称
会议室预约系统

## 项目概述
一套用于员工预约会议室和管理员管理会议室资源的系统。

## 角色

| 角色名称 | 描述 |
|----------|------|
| 员工 | 查看会议室状态、预约会议室、取消预约、查看自己的预约记录 |
| 部门经理 | 审批本部门的会议室预约申请、查看本部门预约记录 |
| 系统管理员 | 管理会议室信息、设置会议室设备、查看所有预约记录 |

## 功能需求

| 编号 | 名称 | 描述 | 相关角色 | 优先级 |
|------|------|------|----------|--------|
| F001 | 会议室浏览 | 员工可以查看所有会议室的名称、容量、设备、可用时间段 | 员工 | 中 |
| F002 | 预约申请 | 员工可以选择日期、时间段、会议室发起预约申请 | 员工 | 中 |
| F003 | 预约审批 | 部门经理审批本部门员工的预约申请 | 部门经理 | 中 |
| F004 | 取消预约 | 员工可以在会议开始前2小时取消预约 | 员工 | 中 |
| F005 | 预约查看 | 员工可以查看自己的预约记录，经理可以查看本部门的预约 | 员工, 部门经理 | 中 |
| F006 | 会议室管理 | 管理员添加、修改、删除会议室信息 | 系统管理员 | 中 |
| F007 | 设备管理 | 管理员设置会议室设备（投影仪、白板、视频会议等） | 系统管理员 | 中 |

## 核心实体

### 员工
系统中的员工用户
属性: 员工ID, 姓名, 部门

### 部门经理
部门经理角色
属性: 经理ID, 姓名, 部门

### 系统管理员
系统管理员角色
属性: 管理员ID, 姓名

### 会议室
会议室资源
属性: 名称, 容量, 设备, 可用时间段

### 设备
会议室设备
属性: 设备类型, 状态

### 预约记录
会议室预约记录
属性: 预约ID, 日期, 时间段, 会议室, 员工, 状态

## 业务约束

- **C001**: 同一会议室同一时间段只能有一个预约
- **C002**: 预约的会议室不能超过可用时间范围
- **C003**: 30人以上大型会议室需要部门经理审批
- **C004**: 小型会议室（10人以下）无需审批，直接预约成功

## 异常流程

- **E001**: 会议室已被预约时，提示'该时段会议室已被占用' (触发: 会议室已被预约, 处理: 提示'该时段会议室已被占用')
- **E002**: 尝试预约过去的时间段时，提示'不能预约已过去的时间' (触发: 尝试预约过去的时间段, 处理: 提示'不能预约已过去的时间')
- **E003**: 超过取消期限尝试取消时，提示'已超过取消期限' (触发: 超过取消期限尝试取消, 处理: 提示'已超过取消期限')

## 非功能需求

- **性能**: 预约操作响应时间不超过1秒
- **性能**: 支持至少50个并发预约请求
- **数据管理**: 预约数据保留至少1年
